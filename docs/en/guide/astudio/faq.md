# AStudio FAQ

> Source: [Official AStudio documentation](https://agent.xfyun.cn/studio-guide/faq) · Checked: 2026-10-26. Product behavior and availability may change; consult the current official page.

## Why did a task enter a project?

The project entry uses the active workspace. For standalone work, use Daily or the independent-task section.

## Must I select Plan or Goal mode?

No. Send ordinary requests directly; use Plan for prior review or Goal for continued execution.

## Can I restore archived tasks?

Yes, under Settings > Archived. Archiving is not deletion.

## What if a preview cannot be edited?

Request spreadsheet, image and PDF edits in conversation, then refresh. Describe the location and desired result when website element selection cannot target content such as Canvas.

## Can I change automation?

The current FAQ supports creation, disabling and deletion, but not direct modification. Test manually; recreate when adjustments are needed.

## How do I report problems?

Check the installer source and supported system, then consult [official troubleshooting](https://agent.xfyun.cn/studio-guide/faq). Send reproduction steps, versions and relevant screenshots through Settings > Feedback.
