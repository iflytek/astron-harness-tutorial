# AStudio Tips

> Source: [Official AStudio documentation](https://agent.xfyun.cn/studio-guide/tips) · Checked: 2026-10-26. Product behavior and availability may change; consult the current official page.

## Make requests concrete

Clarify uncertain goals before execution. With reference material, identify the structure, tone or layout to follow. Review a plan before changes spanning several files.

## Respond to the actual result

Use conversation for broad changes, element selection for local interface feedback, and direct editing for small text adjustments. Describe the location, current behavior and desired result.

## Preserve useful context

Before moving to a new task, prepare a handover with background, decisions, constraints, progress and next steps. Turn repeatable procedures and checks into a personal skill.

## Validate automation

Run new automation manually once. Check its input, output and save location before relying on the schedule.
