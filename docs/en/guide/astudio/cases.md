## Literature research

The official example explores Transformer research. For your own exercise, specify the research question, date range and selection criteria. Ask for verifiable sources and check relevance.

Practice prompt: “Create a table of relevant papers with titles, years, source links and reasons for inclusion. Flag information you cannot verify.”

## Website prototype

The official website example uses Plan mode for Skill discovery. Establish the audience, page structure, sources and update requirements before implementation, then validate the preview.

Practice prompt: “Propose a personal knowledge directory. Explain navigation and search behavior before implementing it.”
