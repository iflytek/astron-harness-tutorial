# AStudio Core Features

> Source: [Official AStudio documentation](https://agent.xfyun.cn/studio-guide/features) · Checked: 2026-10-26. Product behavior and availability may change; consult the current official page.

## Daily and Projects

Daily creates a workspace for standalone work. Projects uses a local folder you select for ongoing files or code. Check the active project before starting a task.

## Task modes

| Mode | Use |
| --- | --- |
| Default | Send a request directly |
| Plan | Enable under “+”, review the plan, then start implementation |
| Goal | Enable under “+” for continued progress; add requirements, pause or clear the goal |

## Review deliverables

Text supports editing, comments, excerpts and version comparison. Request spreadsheet, image and PDF changes through conversation, then refresh. Websites support interaction and element selection; request a public link when ready.

## Tools and organization

Inspect files and diffs, run tests in the terminal, and review Git state. Choose an approval policy appropriate to the work. Create automation through its page or conversation, and configure extensions in the plugin center. Search, pin or archive tasks; restore them under Settings > Archived.
