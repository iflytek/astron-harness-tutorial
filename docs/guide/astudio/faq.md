# AStudio 常见问题

> 来源：[AStudio 官方文档](https://agent.xfyun.cn/studio-guide/faq) · 核对日期：2026-10-26。功能与可用性可能调整，请以官方当前页面为准。

## 独立任务为什么进入了项目？

项目入口会关联当前工作空间。创建独立任务请切换“日常”，或使用项目中的“独立任务”区域。

## 需要总是开启规划或目标模式吗？

不需要。普通任务可直接发送；先审阅方案时用规划模式，持续多轮推进时用目标模式。

## 归档后还能继续吗？

在“设置 > 已归档”中恢复。归档用于整理列表，不等于删除。

## 预览里不能直接修改怎么办？

表格、图片和 PDF 的调整通过对话完成，然后刷新。网页点选无法定位 Canvas 等元素时，用文字描述位置与预期效果。

## 自动化设置错了怎么办？

官方当前支持创建、禁用与删除，暂不支持直接修改已有自动化。先手动运行验证；需要调整时可删除旧任务后重新创建。

## 安装异常或其他问题如何处理？

核对安装来源和支持的系统，再查看[官方故障排查](https://agent.xfyun.cn/studio-guide/faq)。其他问题可在“设置 > 建议反馈”中提供复现步骤、版本及必要截图。
