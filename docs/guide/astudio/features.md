# AStudio 核心功能

> 来源：[AStudio 官方文档](https://agent.xfyun.cn/studio-guide/features) · 核对日期：2026-10-26。功能与可用性可能调整，请以官方当前页面为准。

## 日常与项目

“日常”适合独立任务，系统为其建立工作目录；“项目”关联你选择的本地文件夹，适合持续维护资料或代码。新建任务前先检查当前项目，避免把独立任务放进错误目录。

## 任务模式

| 模式 | 用法 |
| --- | --- |
| 默认 | 直接发送需求 |
| 规划模式 | 输入框“+”中开启，审阅方案并确认“开始实现” |
| 目标模式 | 输入框“+”中开启，围绕目标持续推进；可补充要求、暂停或清除目标 |

## 查看与调整成果

文本支持编辑保存、行内评论、引用片段和版本对比。表格、图片和 PDF 通过对话提出修改，完成后刷新预览。网页可切换交互体验与元素点选，完成后请求发布分享地址。

## 项目、权限与扩展

文件树和 Diff 用于检查变更；终端用于运行测试；版本管理用于查看 Git 状态。权限选项包含默认“帮我批准”、“请求批准”和“完全访问”，按任务范围选择。

自动化可通过页面或对话创建；插件中心用于发现、安装和配置外部能力。任务可搜索、置顶、归档，并从“设置 > 已归档”恢复。
