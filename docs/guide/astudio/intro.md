# AStudio 介绍与定位

> 来源：[AStudio 官方文档](https://agent.xfyun.cn/studio-guide/intro) · 核对日期：2026-10-27。功能与可用性可能调整，请以官方当前页面为准。

## AStudio 是什么

AStudio 是面向多类工作任务的 AI 生产力工作台。你提出目标并补充资料，它可以规划步骤、使用工具并交付文档、表格、网页、图片或代码。成果出现在预览区后，还可以继续对话或针对具体位置修改。

## 从哪里开始

| 你的需求 | 建议入口 |
| --- | --- |
| 第一次体验 | [安装并完成第一个任务](./quickstart) |
| 处理一次独立工作 | 使用“日常”，附上参考文件 |
| 持续维护本地资料或代码 | 使用“项目”，关联对应文件夹 |
| 执行前确认方案 | [规划模式](./features#任务模式) |
| 了解消费与信息处理 | [套餐与积分](./pricing)、[客户端隐私政策](./agreements/privacy-client) |

本栏目覆盖 AStudio；云端助手 AstronClaw 和桌面搭子 Loomy 各有独立教程。三款产品的功能和计费规则请分别查看，避免混用。
