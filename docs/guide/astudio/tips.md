# AStudio 使用技巧

> 来源：[AStudio 官方文档](https://agent.xfyun.cn/studio-guide/tips) · 核对日期：2026-10-26。功能与可用性可能调整，请以官方当前页面为准。

## 把要求变得具体

方向不明确时，先讨论目标再执行；有参考材料时，说明要借鉴的是结构、语气还是视觉布局。涉及多个文件的修改，先用规划模式核对范围。

## 依据实际成果反馈

整体方向通过对话调整，局部界面用点选反馈，少量文本直接编辑。描述“哪里、现在怎样、希望怎样”，比泛泛要求更容易验证。

## 保存可复用的上下文

长对话结束前，整理背景、已确认结论、约束、进度和下一步，作为新任务的交接材料。重复任务中形成的步骤和检查标准，可提炼成个人技能。

## 验证自动化

自动化创建后先手动运行一次，核对输入资料、产出内容和保存位置。实际结果符合预期后再依赖定时执行。
