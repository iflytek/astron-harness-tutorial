# AStudio 套餐与积分

> 来源：[AStudio 官方文档](https://agent.xfyun.cn/studio-guide/pricing) · 核对日期：2026-10-26。功能与可用性可能调整，请以官方当前页面为准。

## 套餐如何选择

官方提供体验版、标准版与高级版。它们的月度积分、每日登录奖励、加购折扣和资源权益不同；单月购买、连续包月与连续包年的价格也不同。

请在[官方价格页](https://agent.xfyun.cn/studio-guide/pricing)对照当前套餐表，并在付款页确认金额、周期及优惠条件。本教程不把限时促销价作为长期承诺。

## 积分有效期

| 类型 | 官方当前说明 |
| --- | --- |
| 新用户奖励 | 1,000 积分，3 个月有效 |
| 每日登录奖励 | 领取后 31 天有效 |
| 套餐积分 | 当前会员计费周期内使用；年付也按月刷新 |
| 加购积分 | 当前会员计费月内使用 |

具体到期时间以积分中心为准。积分用于模型或收费 API 调用，可在任务记录中查看消耗。官方按到期先后扣减；到期相同时，依次使用赠送、套餐和加购积分。

## 订阅前核对

确认本期结束时间、自动续费状态和下一次扣费金额。官方当前不支持周期中途切换档位；取消续费后，已付费周期权益保留到期。阅读[订阅协议](./agreements/product-subscription-service)与[续费协议](./agreements/auto-renewal-service)。
