# AStudio official assets

The logo and illustrations in this directory were downloaded from the official AStudio documentation at https://agent.xfyun.cn/studio-guide/ on 2026-10-27.

`assets.json` records the exact source URL, associated article, Chinese and English captions, local path and SHA-256 checksum for each illustration. There are 56 article images, including two community QR codes. Navigation arrows and other site controls are excluded.

The original screenshots retain their Chinese interface. English tutorial pages provide English captions. The files are used as product reference material; product marks and screenshots belong to their respective rights holders, and the repository license does not grant additional rights to those marks.

Run `npm run docs:check-images` to compare current official images with the local copies, or `npm run docs:sync-images` to refresh them. Review changed illustrations, captions and placement in both language versions before committing.
